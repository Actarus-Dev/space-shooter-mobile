# Space Shooter Mobile

Version mobile-optimisée du jeu **Space Shooter** (v10) — 100 % locale, sans dépendances externes.

- Canvas interne 960×540 (16:9), redimensionné en CSS pour s'adapter à l'écran.
- Contrôles tactiles : stick virtuel + boutons FIRE / RAPID (Pointer Events).
- Plein écran automatique au démarrage et à la rotation en paysage.
- 16 types d'ennemis, 5 boss, musique chiptune procédurale, SFX WebAudio.
- Compatible clavier (WASD + Espace + Maj) et manette Xbox.

Jouez directement depuis cette page, ou ouvrez le fichier `index.html` localement.
